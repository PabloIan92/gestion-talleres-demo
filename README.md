# Sistema de Gestión para Talleres (Mecánica y Carrocería) — Demo Interactiva

Demo pública e interactiva de software de gestión integral para talleres mecánicos, de chapa y pintura, y centros de carrocería y sacabollos (PDR).

## 🚀 Probar la Demo Online
**URL directa:** [https://pabloian92.github.io/gestion-talleres-demo/](https://pabloian92.github.io/gestion-talleres-demo/)

---

## 🛠️ Características Principales

1. **Gestión Integral de Servicios Automotrices:**
   - Mecánica General y Diagnóstico Computarizado
   - Service y Mantenimiento Periódico (Fluidos, Filtros, Frenos)
   - Chapa, Pintura y Sacabollos Artesanal (PDR)
   - Gestión de Siniestros y Compañías de Seguros

2. **Check-in y Recepción con Relevamiento Exterior de 16 Zonas:**
   - Registro de kilometraje actual, combustible y orden de trabajo.
   - Diagrama interactivo de 16 paneles (4 guardabarros, 2 parantes, caja de camionetas, capot, techo, puertas, paragolpes) para constatar el estado exterior al ingresar y evitar reclamos.

3. **Planilla de Control en Tiempo Real (9 Etapas Operativas):**
   - Seguimiento visual por semáforos desde el ingreso hasta el cobro.
   - Alerta roja "Esperando Repuesto" para piezas faltantes de mecánica o chapa.
   - Indicador de permanencia (días en etapa).

4. **Multirol Interactivo para Demostraciones:**
   - 👑 **Dueño / Gerencia:** Métricas de rentabilidad, facturación, control de stock y planilla general.
   - 📋 **Recepción / Asesor de Servicio:** Admisión de vehículos, turnos, cotización y firma de conformidad de retiro.
   - 🔧 **Taller / Mecánico:** Lista de boxes, tareas asignadas, pedido de repuestos y chequeo final.

5. **Módulos Administrativos:**
   - Control de Stock de repuestos mecánicos y consumibles.
   - Informes de Facturación y Cobranzas mensuales.
   - Firma digital táctil en pantalla para la entrega del vehículo.
